## Local execution

- Docker Desktop engine 29.8.0 started after its stopped `Docker/run` socket directory was moved to a dated backup inside the same local Docker directory. This was a reversible workaround for the Windows `sailor-ingest.sock.stale` startup error; it is not proof of a permanent Docker fix.
- `docker compose up -d postgres mailpit`: PostgreSQL and Mailpit were running and healthy.
- `cd backend; .\mvnw.cmd test`: run twice. Each run reported **73 tests, 0 failures, 0 errors, 0 skips, BUILD SUCCESS**. Testcontainers started PostgreSQL 17.11, Flyway migrations ran, and Hibernate schema validation completed. The second run used fresh Testcontainers state. The tests exercised migration/constraints, tenant queries, unique IDs and email, issuance and revocation journals, security, concurrency, artifacts, and delivery behavior.
- `cd backend; .\mvnw.cmd -Dtest=MailpitSmokeIT test` with `MAILPIT_SMOKE=true`: **1 test, 0 failures, 0 errors, 0 skips**. It sent a synthetic multipart issuance email with a PDF attachment to local Mailpit. This does not establish real mailbox delivery.
- `cd frontend; npm run lint`, `npm test`, `npm run build`: all passed; **31 frontend tests** passed.
- `cd blockchain; npm run typecheck`, `npm test`, `npm run coverage`: all passed; **8 contract tests** passed. Coverage reported **100% statements and lines** for `CertificateRegistry.sol`.

The default backend run does not include opt-in `LocalChainIntegrationIT`; those tests require a separate local Hardhat RPC and deployment. The hosted issuance proof below is independent evidence for a real Sepolia transaction, not a replacement for the local-chain suite.
